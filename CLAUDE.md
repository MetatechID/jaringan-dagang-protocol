# Repository workflow

- Always work on `main`, not a staging or feature branch. Do not create additional feature branches or worktrees.
- Read `README.md` and `TECHNICAL.md` before making changes; follow the relevant package instructions and tests.
- Preserve local changes and existing branches. Do not automatically stash, reset, or merge history to switch branches; stop and report an unsafe checkout.
- Commits, pushes, deployments, package publication, and remote default-branch changes require explicit user authorization. Working on `main` does not authorize these actions.
- Keep this public repository free of private configuration, credentials, and company-specific source.
